# 手动字幕擦除 (SubtitleEraser)

加载视频 → 按时间段框选画面中的文字 → 一键用 IOPaint(lama) 把框内文字擦除。
框的位置和时段**精确到帧**，存在工程 JSON 里可反复修改复用。

## 环境准备

需要一个装了 `PySide6` + `iopaint`（torch）的 Python 环境，并在项目根新建
`local_config.json`（**不入版本库**）指明路径：

```json
{
  "python":        "C:/envs/iopaint/Scripts/python.exe",
  "detect_python": "C:/envs/ocr/Scripts/python.exe",
  "model_dir":     "D:/models"
}
```

| 字段 | 说明 | 对应环境变量 |
|---|---|---|
| `python` | 跑本项目的解释器 | `SUBERASER_PYTHON` |
| `detect_python` | 跑自动检测（RapidOCR）的解释器，需装 `rapidocr-onnxruntime` + `onnxruntime-gpu` | `SUBERASER_DETECT_PY` |
| `model_dir` | lama 权重缓存目录 | `SUBERASER_MODEL_DIR` |
| `test_video` | 自测素材路径（可选） | `SE_TEST_VIDEO` |

环境变量优先级高于配置文件；只写用得上的字段即可。

## 启动

```
双击 启动.bat
```
或 `<你的解释器> run.py`

首次启动会在后台加载 lama 模型（10~50 秒），状态栏右侧显示 `模型 lama | 设备 cuda` 后即可擦除。

## 操作流程

1. **打开视频**（Ctrl+O）→ 自动探测分辨率/帧率/总帧数
2. **定位到字幕出现的帧** → 在画面上**按住左键拖出框**
   （出点直接写成末帧号：框以**虚线**一直生效到末尾，往后拉进度条时框始终可见）
3. 跳到字幕消失的帧，按 **O** 把出点定到当前帧（框变实线）。按 **I** 定入点，
   也可以在右侧面板直接填起止帧，或用「入点=开头」「出点=末尾」按钮
4. 重复 2~3 给其它位置的字幕加框
5. **Ctrl+S** 保存工程（视频同目录 `xxx.suberase.json`，下次打开视频自动载入）
6. 点 **开始擦除** → 选输出路径 → 等进度条走完

## 快捷键

| 键 | 作用 |
|---|---|
| `←` / `→` | 逐帧后退 / 前进 |
| `Shift + ←/→` | ±10 帧 |
| `Ctrl + ←/→` | ±1 秒 |
| `Home` / `End` | 首帧 / 末帧 |
| `Space` | 播放 / 暂停 |
| `I` / `O` | 选中框的入点 / 出点 = 当前帧 |
| `[` / `]` | 选中框的入点 = 开头（第 0 帧） / 出点 = 末尾（末帧号） |
| `Delete` | 删除选中框 |
| `Esc` | 取消选中 |
| `Ctrl+S` / `Ctrl+O` | 保存工程 / 打开视频 |
| `Ctrl+B` | 批量擦除 |

鼠标：拖空白 = 新建框；拖框内 = 移动；拖四角 = 缩放；点时间轴 = 跳转。

## 框的显示规则

- **实线 = 两端都已定**；**虚线 = 有一端贴在开头/末尾**：
  - 新拖的框 → 出点直接写成**末帧号**（虚线一直生效到末尾），按 `O` 改成当前帧
  - 「入点=开头」→ 起始帧写 **0**；「出点=末尾」→ 结束帧写**末帧号**
  - 工程 json 里存的就是具体帧号（没有额外的"未定"标志位），可直接手改：
    起始帧为 `0` 即代表从开头，结束帧为末帧号即代表到末尾
- **当前帧不生效的框（已过期/还没开始）**：默认**不绘制、也不参与鼠标操作**，
  所以在旧框所在位置可以直接拖出新框。在右侧列表选中它时，会以虚影显示并标注
  `(不在当前帧)`，方便确认位置（虚影不能拖动）
- 想一次看到所有框：勾选工具栏 **显示非活跃框**

## 批量擦除

工具栏 **批量擦除**（`Ctrl+B`）：一次选多个工程 json，串行处理。

- 每个工程用**自己的 settings 和输出路径**（工程里的 `output` 字段）
- 默认勾选「跳过输出已存在的」= 断点续跑，中途加新任务重跑不会重算已完成的
- 可中途取消：跑完当前这条就停，已产出的文件保留
- 列表显示每个工程的视频、框数、输出、状态；底部有总进度条

实测：1280x720/3s + 960x540/2s 两个工程共 150 帧，串行 52.6s。

## 擦除原理

- **只处理被框覆盖的帧**，其余帧原样直通，不推理
- 帧按"活跃框集合"分段，段内 crop 区域一致 → 多帧组 **真 batch**（`[B,C,H,W]` 一次前向）
- 只裁字幕带（框合并 + margin 外扩）送进模型，不推理全图 → 显存低、速度快、不破坏画面其它部分
- IOPaint 以库形式内嵌进程（不走 HTTP），省掉 base64 与网络开销

实测（RTX 3060 12G，NVENC 输出）：竖屏 720x1280、439 帧全片擦除 37.8s（约 11.6 帧/秒）；
只擦 61 帧的片段 9.6s（其余帧直通）。

## 参数（右侧面板）

| 参数 | 默认 | 说明 |
|---|---|---|
| 外扩 margin | 48 | crop 区在框外多带的上下文，太小修复会糊 |
| mask 膨胀 | 3 | mask 向外膨胀像素，覆盖文字描边 |
| batch | 0(自动) | 按显存预算自动；显存富余可手动调大 |
| 编码器 | auto | auto→NVENC，失败回落 x264 |
| 质量 cq/crf | 18 | 越小质量越高体积越大 |

## 工程文件格式

```json
{
  "version": 1,
  "video": "D:/x/源片.mp4",
  "output": "D:/x/源片_clean.mp4",
  "meta": {"fps": 30.0, "width": 1920, "height": 1080},
  "boxes": [{"id": "a1b2c3d4", "x": 200, "y": 900, "w": 1520, "h": 140,
             "start": 120, "end": 780, "enabled": true, "label": ""}],
  "settings": {"margin": 48, "dilate": 3, "batch_size": 0, "encoder": "auto", "crf": 18}
}
```
坐标为源视频原始像素，`start/end` 为闭区间帧号。

## 自测

用一段真实竖屏视频素材做端到端验证，不依赖自造视频。素材**不入版本库**，
用 `SE_TEST_VIDEO` 或 `local_config.json` 的 `test_video` 指向本地文件；
未配置或文件不存在时，相关测试自动跳过（返回码 0）。

```bash
<你的解释器> tests/test_smoke.py    # seek精度/引擎batch/端到端擦除
<你的解释器> tests/test_gui.py      # GUI 全流程（offscreen 模拟拖框/键盘/擦除）
<你的解释器> tests/test_batch.py    # 批量串行 + 断点续跑
<你的解释器> tests/test_detect.py   # 分轨道/自动检测/工程格式
```

端到端判据（不靠目测）：自动定位素材字幕行 → 擦除后框内**白色文字像素数应归零**
（实测 8641 → 0），框外差异 ≤ 编码噪声，时段外帧逐帧直通。

## 已知限制

- 可变帧率(VFR)视频按平均帧率换算帧号，可能有 1 帧偏差（状态栏会提示）
- 总帧数由 `时长×帧率` 估算时状态栏标"（估算）"，以容器记录的 `nb_frames` 优先
- 不做撤销栈，删错框重新拖一个
- 只擦框内像素；如果字幕有阴影/描边超出框，调大框或调大 mask 膨胀
