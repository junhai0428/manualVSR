# 手动字幕擦除 (SubtitleEraser)

加载视频 → 按时间段框选画面中的文字 → 一键用 IOPaint(lama) 把框内文字擦除。
框的位置和时段**精确到帧**，存在工程 JSON 里可反复修改复用。

## 启动

```
双击 启动.bat
```
或 `<MAIN_ENV>\Scripts\python.exe run.py`

首次启动会在后台加载 lama 模型（10~50 秒），状态栏右侧显示 `模型 lama | 设备 cuda` 后即可擦除。

## 操作流程

1. **打开视频**（Ctrl+O）→ 自动探测分辨率/帧率/总帧数
2. **定位到字幕出现的帧** → 在画面上**按住左键拖出框**
3. 框建好后 `start = end = 当前帧`。跳到字幕消失的帧，按 **O** 把出点设到当前帧
   （按 **I** 设入点。也可以在右侧面板直接填起始帧/结束帧）
4. 重复 2~3 给其它位置的字幕加框
5. **Ctrl+S** 保存工程（视频同目录 `xxx.suberase.json`，下次打开视频自动载入）
6. 点 **开始擦除** → 选输出路径 → 等进度条走完

## 快捷键

| 键 | 作用 |
|---|---|
| `←` / `→` | 逐帧后退 / 前进 |
| `Shift + ←/→` | ±10 帧 |
| `Ctrl + ←/→` | ±1 秒 |
| `Home` / `End` | 首帧 / 末帧 |
| `Space` | 播放 / 暂停 |
| `I` / `O` | 选中框的入点 / 出点 = 当前帧 |
| `Delete` | 删除选中框 |
| `Esc` | 取消选中 |
| `Ctrl+S` / `Ctrl+O` | 保存工程 / 打开视频 |
| `Ctrl+B` | 批量擦除 |

鼠标：拖空白 = 新建框；拖框内 = 移动；拖四角 = 缩放；点时间轴 = 跳转。

## 框的显示规则

- **当前帧生效的框**：实线彩色 + 序号/时段标签，可拖动、四角可缩放
- **当前帧不生效的框（已过期/还没开始）**：默认**不绘制、也不参与鼠标操作**，
  所以在旧框所在位置可以直接拖出新框。在右侧列表选中它时，会以虚影显示并标注
  `(不在当前帧)`，方便确认位置（虚影不能拖动）
- 想一次看到所有框：勾选工具栏 **显示非活跃框**

## 批量擦除

工具栏 **批量擦除**（`Ctrl+B`）：一次选多个工程 json，串行处理。

- 每个工程用**自己的 settings 和输出路径**（工程里的 `output` 字段）
- 默认勾选「跳过输出已存在的」= 断点续跑，中途加新任务重跑不会重算已完成的
- 可中途取消：跑完当前这条就停，已产出的文件保留
- 列表显示每个工程的视频、框数、输出、状态；底部有总进度条

实测：1280x720/3s + 960x540/2s 两个工程共 150 帧，串行 52.6s。

## 擦除原理

- **只处理被框覆盖的帧**，其余帧原样直通，不推理
- 帧按"活跃框集合"分段，段内 crop 区域一致 → 多帧组 **真 batch**（`[B,C,H,W]` 一次前向）
- 只裁字幕带（框合并 + margin 外扩）送进模型，不推理全图 → 显存低、速度快、不破坏画面其它部分
- IOPaint 以库形式内嵌进程（不走 HTTP），省掉 base64 与网络开销

实测：720p 120 帧全程 13.9s（约 8.6 帧/秒，RTX 3060 12G，NVENC 输出）。

## 参数（右侧面板）

| 参数 | 默认 | 说明 |
|---|---|---|
| 外扩 margin | 48 | crop 区在框外多带的上下文，太小修复会糊 |
| mask 膨胀 | 3 | mask 向外膨胀像素，覆盖文字描边 |
| batch | 0(自动) | 按显存预算自动；显存富余可手动调大 |
| 编码器 | auto | auto→NVENC，失败回落 x264 |
| 质量 cq/crf | 18 | 越小质量越高体积越大 |

## 工程文件格式

```json
{
  "version": 1,
  "video": "D:/x/源片.mp4",
  "output": "D:/x/源片_clean.mp4",
  "meta": {"fps": 30.0, "width": 1920, "height": 1080},
  "boxes": [{"id": "a1b2c3d4", "x": 200, "y": 900, "w": 1520, "h": 140,
             "start": 120, "end": 780, "enabled": true, "label": ""}],
  "settings": {"margin": 48, "dilate": 3, "batch_size": 0, "encoder": "auto", "crf": 18}
}
```
坐标为源视频原始像素，`start/end` 为闭区间帧号。

## 已知限制

- 可变帧率(VFR)视频按平均帧率换算帧号，可能有 1 帧偏差（状态栏会提示）
- 总帧数由 `时长×帧率` 估算时状态栏标"（估算）"，以容器记录的 `nb_frames` 优先
- 不做撤销栈，删错框重新拖一个
- 只擦框内像素；如果字幕有阴影/描边超出框，调大框或调大 mask 膨胀
